# Retirement Guaranteed Income Calculator

A standalone, locally runnable HTML snapshot of the Retirement Fund / Guaranteed Income Calculator.

## Test

Open `index.html` in Chrome or Edge. No network access is needed for page styling or calculation.

## What was archived

- `index.html` — adapted, self-contained version of the user-provided saved webpage.
- `archive/original-saved.html` — untouched HTML capture, retained for provenance. The original expects its captured `*_files` folder, which is **not** included in the repository. Use `index.html` for local testing.

Source URL: https://9ftec.com/tool-h5/retirement_guaranteed_income_calculator.html

The standalone copy removes the optional embedding bridge, reuses CSS already embedded in the capture, and substitutes simple built-in symbols for Font Awesome glyphs. The saved single-life and joint-life payout lookup tables, numerical calculator functions and language UI remain as supplied. Insurer contract guarantees and rates have **not** been independently verified.
